# Playwright Java Automation Testing

## Overview

This repository documents my 30-day learning journey in web automation testing using Java and Playwright.

The goal is to develop practical skills in automated UI testing, API testing, test design, debugging, and test reporting.

## Tech Stack

- Java 21
- Playwright for Java
- Maven
- JUnit
- Git and GitHub

## Learning Roadmap

- [ ] Week 1: Java fundamentals and Playwright basics
- [ ] Week 2: Locators, web interactions, and UI testing
- [ ] Week 3: JUnit, test organization, and Page Object Model
- [ ] Week 4: API testing, cross-browser testing, and final project

## Repository Structure

- `learning-log/`: Daily learning notes and progress
- `test-cases/`: Test scenarios and test cases
- `src/test/java/`: Automation test source code
- `docs/`: Test plans, bug reports, and test summaries
